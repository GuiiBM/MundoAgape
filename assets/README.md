## Imagens do site

- `logo-left.png`, `logo-right.png`, `logo-mundo-agape.png` — arquivos originais em alta resolução.
- `web/` — versões otimizadas que o site realmente carrega (PNG + WebP), a imagem de
  compartilhamento `og-image.jpg` (1200×630) e o `apple-touch-icon.png`.
- `favicon.svg` — ícone da aba do navegador.

Se trocar algum logo, gere de novo a versão correspondente em `web/`
(largura de ~720px é suficiente) para manter o site leve.
